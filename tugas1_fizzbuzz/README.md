# Tugas1_fizzbuzz
program menampilkan angka 1 sampai 100 pakai aturan FizzBuzz.
- kelipatan 3 dan 5 -> FizzBuzz
- kelipatan 3 -> Fizz
- kelipatan 5 -> Buzz
- selain itu -> angka aslinya

## cara menjalankannya ##
Pastikan Python sudah terinstall, lalu:
    python fizzbuzz.py

## cara menjalankan testingnya ##
Install pytest dulu:
    pip install -r requirements.txt

Lalu jalankan:
    pytest

## struktur filenya ada ##
- fizzbuzz.py - program yang utama
- test_fizzbuzz.py - unit testingnya
