# tugas2_todo_app
Aplikasi Todo List sederhana dengan fitur CRUD (Create, Read, Update, Delete).

## Teknologi yang diapaki di sini
- Python (Flask)
- HTML, CSS, Vanilla JavaScript
- SQLite (Database)

## Cara Menjalankannya
1. Install Flask dulu: `pip install -r requirements.txt`
2. Jalankan perintah: `python app.py`
3. Buka `http://127.0.0.1:5000` di browser.

## Fitur
- Tambah tugas baru
- checkbox
- Edit tugas
- Hapus tugas
